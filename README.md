## Currently building                                                                                                 
**LocalDoors** — a Linux vulnerability scanner with an embedded local LLM, a single-file Python tool designed to run   on weak, offline machines. Plain code determall local model (via llama.cpp) only explains findings in plain language and prioritizes them. Always produces an HTML report, with or without the AI layer. Covers  10 checks: open ports/services, SSH hardeninfirewall status, root/sudo users, emptypasswords, suspicious SUID files, world-writable paths in system directories, /etc/shadow permissions, and brute-force attempts in auth.log.
