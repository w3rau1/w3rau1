## Currently building

**Linux vulnerability scanner with an embedded local LLM** — a single-file Python tool designed to run on weak, offline machines. Plain code determines facts and severity; a small local model (via llama.cpp) only explains findings in plain language and prioritizes them. Always produces an HTML report, with or without the AI layer. Covers 10 checks: open ports/services, SSH hardening, pending security updates, firewall status, root/sudo users, empty passwords, suspicious SUID files, world-writies, /etc/shadow permissions, and brute-force attempts in auth.log.
